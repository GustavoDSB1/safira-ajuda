---
title: Conta GitHub
---

A conta da Safira usa o **GitHub**. Com ela você publica suas notas na web com um clique.

## Criar uma conta
Em **Configurações → Geral → Conta GitHub**, clique em **Criar conta**. O site do GitHub abre para você se cadastrar (é grátis).

## Entrar
1. Clique em **Entrar com GitHub**.
2. Aparece um código de 8 letras. Clique em **Copiar código e abrir o GitHub**.
3. No GitHub, cole o código e clique em **Authorize**.
4. A janela da Safira fecha sozinha e mostra **Conectado como …**.

A Safira pede permissão só para ler seu perfil e gerenciar **repositórios públicos** (é onde o site de notas fica). Ela nunca vê sua senha.

## Sair
Clique em **Sair** na mesma tela. Para revogar o acesso por completo, vá em GitHub → Settings → Applications → Authorized OAuth Apps.

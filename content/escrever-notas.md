---
title: Escrever notas
---

A Safira usa **Markdown**: texto simples com alguns símbolos para formatar.

| Você escreve | Resultado |
|---|---|
| `# Título` | título grande (use `##` e `###` para subtítulos) |
| `**negrito**` | **negrito** |
| `*itálico*` | *itálico* |
| `==destaque==` | texto marcado |
| `- item` | lista |
| `- [ ] tarefa` | caixa de seleção |
| `> citação` | citação |

## Ligar notas
Escreva `[[` e o nome de outra nota para criar um **link**. Se a nota não existir, ela é criada quando você clica no link. Use `[[Nota|texto]]` para mostrar outro texto.

## Imagens e anexos
Arraste uma imagem ou um PDF para dentro da nota. Para mostrar o conteúdo de outra nota dentro desta, use `![[Nome da nota]]`.

## Etiquetas
Escreva `#etiqueta` em qualquer lugar da nota. O painel de etiquetas lista todas elas.

## Modo leitura
`Ctrl+E` alterna entre editar e ler a nota formatada.
